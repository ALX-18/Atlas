## LLM

- **[Microsoft Aion 1.0 Instruct]** — petit modèle de langage de 2,3B, poids ouverts sous licence MIT, sorti le 18/11 (https://llm-stats.com/models/aion-1.0-instruct) — *assez léger pour un rôle de classifieur ou de repli rapide ; le français et le JSON sont à tester.*
- **[CapLite]** — défense contre l'injection de prompt pour les agents à petits modèles (de 1,7B à 12B). L'autorisation des outils se fait en code déterministe. Résultat annoncé sur AgentDojo : 0 attaque réussie sur 15 modèles, avec environ 5 fois moins de tokens que CaMeL. Préprint du 12/11, article du 15/11 (https://casrai.org/news/caplite-prompt-injection-defense-small-language-models-2026) — *même philosophie que le Validator déterministe d'Atlas ; bonne piste pour sécuriser la lecture des mails.*
- **[Tencent Hy4 flash]** — MoE de 224B (12B actifs), texte et image, sorti le 16/11 ; poids ouverts non confirmés (https://llm-stats.com/models/hy4-flash) — *hors gabarit 8 Go.*

## Data et technos

- **[Transformers 5.23.0]** — sorti le 13/11 : réécriture de l'API d'export (`export()` renvoie un `ExportedModel`, `output_path` supprimé de `OnnxConfig`) et 12 breaking changes listés (https://opentools.ai/news/hugging-face-transformers-5-23-0-model-support-and-upgrade-caveats-for-deployers-and-fine-tuners-c7cf8fc7dd) — *à surveiller si un script exporte e5-base en ONNX via transformers ; utile aussi pour le labo HF.*
- **[Hugging Face Inference Providers]** — depuis le 17/11, les requêtes vers les modèles de langage passent par OpenRouter (https://releasebot.io/updates/huggingface) — *concerne le labo, pas Atlas (100 % local).*

## À considérer pour les prochains sprints

- Passer Aion 1.0 Instruct 2.3B sur le banc de modèles (français, JSON structuré, fuite de « réflexion », latence), plutôt comme classifieur ou repli léger que comme LLM principal. Vérifier d'abord qu'une version GGUF existe pour Ollama.
- Lire le préprint CapLite (arXiv:2611.17115, identifiant cité par l'article, non vérifié) et comparer son mécanisme (politique tirée des schémas d'outils + ensemble de référence issu de la demande de l'utilisateur) au Validator d'Atlas, notamment pour les actions déclenchées depuis un mail.
- Si l'export ONNX de multilingual-e5-base passe par l'API exporters de transformers, figer la version de transformers ou adapter le script avant de passer en 5.23.
- Rappel des semaines précédentes, toujours ouvert : les CVE ChromaDB sans correctif (vérifier que seul le PersistentClient embarqué est utilisé, sans aucun port en écoute) ; mise à jour d'Ollama vers v0.40.16. Attention, `/v1/responses` ne tronque plus par défaut, à tester si Atlas utilise cette route.
